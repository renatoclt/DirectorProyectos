# Mapa del sistema

```text
DESCRIPCIÓN BREVE
  ↓
DIRECTOR DE PROYECTOS
  ↓
PROPUESTA EJECUTIVA (2–3 min)
  ↓
ADJUNTOS DETALLADOS
  └── A07 dirección visual y paleta
  ↓
COLOR-SYSTEM
  ├── Paleta A
  ├── Paleta B
  └── Paleta C
  ↓ comparación
RECOMENDACIÓN + TOKENS + CONTRASTE
  ↓
FRONTEND-DESIGN
  ↓
MOCKUP CONCEPTUAL
  ↓
FRONTEND-DESIGN-REVIEW
  ↓
VALIDACIÓN DEL CLIENTE
  ↓
DISCOVERY → DESIGN → PLANNING → aprobación humana → BUILD → QUALITY → DELIVERY
```

## Roles de la propuesta

```text
Director
├── Analista de Negocio
├── Product Manager
├── Diseñador UX UI + color-system + frontend-design
├── Planificador de Proyecto
├── Prototipador UX + frontend-design
└── Gestor de Documentación
```

## Capas de control

- Contrato del agente.
- Herramientas y rutas restringidas.
- Skills reutilizables.
- Escenarios conductuales.
- Baselines.
- Trazabilidad por proyecto.
- Aprobación humana.
