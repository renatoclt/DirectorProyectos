# Perfil comercial reutilizable

Esta carpeta contiene únicamente información comercial confirmada de la empresa. El Director de Proyectos la utiliza para presentarse, indicar disponibilidad y explicar por qué el equipo encaja con una oportunidad.

Completa [COMPANY-PROFILE.md](COMPANY-PROFILE.md) antes de enviar propuestas reales.

Reglas:

- No registrar años de experiencia, clientes, certificaciones, casos de éxito o capacidades que no puedan demostrarse.
- No comprometer horarios, tiempos de respuesta o capacidad que no estén disponibles.
- Cuando un campo siga pendiente, la propuesta debe mostrarlo como `POR CONFIRMAR`.
- Este perfil es reutilizable; la propuesta de cada proyecto debe adaptarlo al contexto del cliente.
